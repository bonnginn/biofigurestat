# Experiment-first architecture evaluation

This directory extends the existing pilot without changing product code or current Gold to fit the UI.

- `PHASE_1_15_CASE_REANALYSIS.md`: natural surfaces for the original 15 cases.
- `adaptive-input-grammar.json` and `ADAPTIVE_INPUT_GRAMMAR.md`: five generic surface contracts.
- `gold-set-45.json`: 15 reanalyzed plus 30 new biology-first Gold cases.
- `raw-realism/`: 12 messy lab-output examples with checksummed manifest.
- `architecture-comparison-45.json`: per-case A/B/C comparison.
- `failure-clusters.json`: input and semantic failure clusters.
- `ARCHITECTURE_EVALUATION.md`: aggregate comparison and verdict.
- `IMPLEMENTATION_PRIORITY_PROPOSAL.md`: non-implementation priority sequence.
- `DECISION_BRIEF.md`: short human review entrypoint.
- `generate-assets.ps1` and `validate-assets.ps1`: reproducible generation and validation.

The folder was authored without Pool D access. Architecture B/C results describe proposed contracts, not implemented UI behavior.
