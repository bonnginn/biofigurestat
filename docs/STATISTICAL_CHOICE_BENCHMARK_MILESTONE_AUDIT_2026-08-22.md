## Open gate

The only requirement that cannot be established from source or headless component tests is the
five-pilot visible browser run in requirement 40, including actual production of all nine files.
The current managed Codex sandbox has previously denied loopback socket binding. The evaluation
launcher and HTTP tests will be attempted again after the source/native verification pass. If the
environment still denies binding, the external operator procedure in
`docs/BENCHMARK_EVALUATION_INFRASTRUCTURE.md` remains the authoritative gate.

The external operator now uses `pnpm dev:evaluation` plus `pnpm evaluation:tunnel` and supplies
only the generated HTTPS root URL to Work. The current managed Codex sandbox still denies the
loopback bind operation, so the live two-process check remains external. No bridge port is tunneled
or exposed directly.
