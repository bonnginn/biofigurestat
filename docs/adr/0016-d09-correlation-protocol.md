# ADR 0016: D09相関を明示的な完全ペアとして扱う

- 状態: accepted
- 日付: 2026-08-20

## 決定

D09はprotocol 0.5.0を使用し、同じ宣言済み実験単位から得た2つの連続測定を、明示的なpair IDで結合する。行順から対応を推測しない。各単位は変数XとYへ1値ずつを持ち、Coreでは3つ以上の完全ペアを必須とする。

ローカル解析エンジン自体も0.5.0へ更新し、D01–D05の既存protocolを保ったままD09を追加した実行版であることを結果に記録する。

WizardはPearson/Spearmanという統計名を最初に選ばせない。科学的な問いとして以下を確認する。

- 直線的な関係を評価する: Pearson
- 単調な関係または順位として評価する: Spearman

Pearsonは相関係数、p値、Fisher変換による信頼区間を返す。Spearmanは相関係数とp値を返し、初期Coreでは信頼区間を断定せず警告する。相関は因果を示さない旨を常に診断へ含める。

## データモデル上の境界

現行ExperimentDesignでは2つの測定チャネルをmatchedな2 conditionとして表現し、1つのcontinuous outcomeを共有する。これはX/Yを同じ実験単位で完全に揃える既存のunit/condition整合性検証を再利用するためのMVP境界である。条件間差の検定としては扱わず、D09 requestだけがX/Yとして解釈する。

## Figure

既定グラフはscatterとし、軸ラベルは2つの測定名から生成する。点は完全な生物学的実験単位を表す。回帰線を相関の必須要素とはせず、将来追加する場合も因果的なfitとして表示しない。
