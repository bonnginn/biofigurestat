# Core Statistical Method Catalog

Status: Internal Alpha, 2026-08-22  
Application: Life Science Analysis App 0.1.0  
Engine: `lsaa-python` 0.14.0; NumPy 2.3.5; SciPy 1.18.0; Statsmodels 0.14.6

Package availability does not guarantee scientific appropriateness. The application must still
preserve the declared experimental unit, matching, grouping, missing-data handling, contrast,
sidedness, transformations, and multiplicity plan.

## Validation tiers

- **Tier A:** maintained public package API, pinned version, deterministic application regression
  and edge-case tests, tested input shaping, documented semantics, and engine/package provenance.
  A completely independent second implementation is not mandatory.
- **Tier B:** complex or ambiguity-prone models requiring stronger reference validation, such as
  mixed models, GLMM, advanced repeated structures, and estimated marginal means.

## Defined but not executable

| Family                                                              | Status and reason                                                                                                                                  |
| ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Arbitrary linear multi-group contrasts                              | Tier B; coefficient semantics, estimands, simultaneous intervals, and validation are not yet contracted                                            |
| Mixed models / GLMM                                                 | Tier B; model, convergence, contrast, and reference validation required                                                                            |
| Complex factor-by-time/repeated                                     | Not supported; never flattened into independent tests                                                                                              |
| Cox/competing-risk survival, omics inference, general dose response | Outside current Core; never coerced into ordinary continuous-group tests. The bounded Michaelis–Menten route is not a general dose-response model. |

## UI and provenance policy

Statistics separates **Recommended**, **Alternatives**, and **Advanced**. Recommendation is advice,
not enforcement. Executed history records the recommended method and the selected request method,
whether they differ, the explicit contrast/correction, engine/package versions, and application
version. Unsupported methods are not clickable.
