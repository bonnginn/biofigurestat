BioFigureStat 0.1.1 Alpha

公開済みプロジェクトの互換性、入力・保存、解析結果の表示と作業画面を改善したAlpha更新です。単回帰は既存の表からStatisticsで選択でき、単一群の基準値比較とWB追加正規化を含みます。統計処理はローカルで実行します。

Windows x64: Setup.exe。Mac: Apple Silicon arm64、macOS 11以降。Mac ZIPを展開してBioFigureStat.appを使用してください。Mac版はad-hoc署名でApple notarizationを取得していません。OSの安全警告は自動で回避しません。

利用情報は明示的な同意時のみ送信し、問題報告は別途、内容プレビューと報告ごとの送信操作を必要とします。研究データやファイルを自動添付しません。Windows/Macの匿名報告送信と認証管理での内容一致・一意性を確認済みです。通信失敗時の入力保持・手動再送は模擬テスト済みで、実回線切断試験は未実施です。

旧公開版からの匿名ファイル互換性と、変更に必要な解析・入力・保存の確認を実施しました。Macの公開用identityは同source/configに対する包装差分の照合で確認しており、通常identityでのGUI全検査は反復していません。別の新規Windows環境でのインストール確認は行っていません。
