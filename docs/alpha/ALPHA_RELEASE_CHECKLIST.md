# Alpha Release Checklist

## Scientific and data integrity

- [ ] Expanded approximately 500-case benchmark reviewed
- [ ] Supported/unsupported boundaries documented
- [ ] Raw revision, save/open, migration, biological-unit, paired/nested/repeated, Methods, and Graph regression gates pass

## Researcher experience

- [x] Privacy-reduced diagnostic export
- [x] Stable error taxonomy and safe next actions
- [x] Local contextual Help and glossary
- [x] Curated synthetic onboarding
- [ ] Critical keyboard/accessibility audit completed on packaged builds
- [ ] 1360×900 and high-DPI visual smoke completed

## Distribution

- [ ] Final name/logo/license approved
- [ ] Platform signing and package identities approved
- [ ] macOS and Windows packaging checklist complete
- [ ] Privacy and known-limitations documents reviewed

Completing sidework does not itself authorize an Alpha release.
