# Alpha Privacy and Security

## Research data

- Normal project data and deterministic statistics stay on the local computer.
- No product-usage event is recorded or queued before an explicit first-run Yes choice. Diagnostic reports are never uploaded automatically.
- Optional product-usage telemetry uses a fixed metadata allowlist. It can record fixed-enum Biological Interview areas (for example condition definition, combination review, or unit relationship), fixed-enum Graph families, and coarse initial-display classifications (for example, whether raw points, a summary, or an uncertainty layer was initially visible), but it cannot contain measurements, table cells, experiment/condition/readout/sample names or IDs, free text, file paths, clipboard content, or project names.
- This is research-data-free usage telemetry, not a claim of complete anonymity. When consent is ON, the allowlist includes a random app-installation ID used to group sessions, a random per-launch session ID, event timestamps, application/build version, OS family, typed workflow/route/category values, bounded interaction counts, and fixed error codes. The IDs are generated by the application and are not derived from researcher input or project content.
- Consent can be changed later from About. Turning it off stops collection and purges the bounded unsent queue and random app-installation ID from the device.
- Upload is possible only when `VITE_USAGE_TELEMETRY_ENDPOINT` is a valid credential-free HTTPS URL, `VITE_USAGE_TELEMETRY_INGEST_KEY` is a valid public ingestion key, and the compiled consent-notice version is explicitly a `remote-*` notice. Missing or invalid configuration performs zero external telemetry requests; a local research-data-free report can still be copied explicitly from About.
- The Alpha collector is implemented for Cloudflare Workers with D1. It independently validates the exact event allowlist, rejects extra fields, bounds request size and per-installation volume, deduplicates events, stores no source-IP field, and deletes stored events after 90 days. Cloudflare may nevertheless process source IP and ordinary HTTP transport metadata while handling the request.
- The current `remote-alpha-2026-08-30` notice requires a fresh choice and discards queues created under the earlier local-only notice. A prior explicit opt-out remains respected. The approved Alpha collector is deployed at `https://biofigurestat-telemetry.biofigurestat.workers.dev/v1/usage` in APAC, with exact CSP/CORS origins, a public ingestion key, a researcher-visible privacy/deletion contact, and 90-day expiry. Builds lacking the complete approved configuration remain fail-closed and make no upload.
- For the initial Public Alpha, this document is the privacy/deletion contact page. Use the in-app
  **問題を報告** form for a deletion or privacy request, identify it as a privacy request, and do not
  include research measurements, project content, filenames, screenshots, or other research data.
  The form shows every outbound field before an explicit send. A dedicated support email may replace
  this route later; the published app contact and this document must be updated together.
- Diagnostic export excludes raw measurements and identifying labels/notes by default.
- Public Alpha problem reports use a separate explicit workflow and endpoint. The application shows the complete outbound content before every send and never sends automatically. Measurements, tables, experiment/condition/readout/sample names or IDs, files and paths, clipboard content, screenshots, and project packages cannot be attached. The form warns researchers not to enter research information.
- Optional privacy-reduced report diagnostics are attached only after a per-report checkbox. They contain app/build version, coarse platform/architecture, current fixed route, fixed error codes and general error classes; they exclude project summaries, structural counts, fingerprints, unstructured error messages, and usage-telemetry IDs.
- An optional reply email is encrypted at field level and is absent from report/triage lists. It requires an explicit authenticated admin request to decrypt and is deleted 30 days after a terminal disposition or with the 90-day report expiry, whichever occurs first.
- Contextual Help uses a local deterministic glossary. No cloud LLM provider, product API key, or automatic model call is configured.
- The optional “外部LLMに相談する” control creates an editable question for the researcher to copy manually. It links to the public, versioned application guide and does not send the prompt or project to an external service. The generated question includes experiment structure or statistical intent but excludes measurement values by default; the researcher controls any later edits and the external service they choose.
- The optional “相談結果から改善要望を作る” step accepts only text the researcher deliberately pastes or writes, labels the external answer as unverified reference material, and copies a reviewable request locally. It does not execute the answer, submit an issue, or upload the request. Researchers should omit measurements and identifying research text.
- Any future automatic external Help provider remains out of scope unless separately approved. It must be opt-in and disclose the exact structured context before first use. Raw measurements remain excluded by default.

## Evaluation isolation

- Evaluation mode requires both a development build and an explicit environment flag.
- The browser receives only a same-origin evaluation path; the bearer token remains in the Vite proxy process.
- The bridge binds to loopback, checks exact Origin and bearer token, limits request size, and stores blind packages outside the repository.
- Bridge responses do not expose server filesystem paths or authentication tokens.
- Cloudflare tunnel commands are development scripts and are not invoked by the production application.

## Desktop boundary

- Tauri capabilities allow core window behavior and explicit open/save dialogs only.
- A restrictive WebView CSP is configured.
- The local Python/packaged sidecar receives validated analysis requests through the Tauri command boundary.
- Diagnostic writing requires a user-selected absolute `.json` path, valid JSON, and a 1 MB limit.
