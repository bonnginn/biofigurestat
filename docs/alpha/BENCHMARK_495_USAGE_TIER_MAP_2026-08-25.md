# Benchmark 495 Usage Tier Map

Date: 2026-08-25  
Status: provisional non-Pool-D map; Graph certification pending targeted reconstruction

## Interpretation rule

The benchmark is not one undifferentiated Gold set. Statistical validity, hierarchy safety, Figure capability, and context-rich reproduction require different evidence.

## Tier definitions

### Tier S — Scientific engine / hierarchy regression

Use for the contract actually encoded by the fixture:

- biological n and technical-observation separation;
- pairing, nesting, repeated identity;
- loader and analysis routing;
- provenance and safe unsupported behavior;
- deterministic numerical regression where reference results exist.

Tier S does not claim paper-message or Figure fidelity.

### Tier G — Graph / Figure capability validation

A case enters Tier G only after a source-backed overlay fixes:

- selected Figure/panel and scientific message;
- X, series, facet, and hierarchical-label roles;
- graph family and raw/summary/error semantics;
- named primary contrast and annotation family;
- control, WT, rescue, or negative-reference role;
- displayed versus inferential unit.

No current historical case is certified Tier G by this audit. Thirty-five cases form the bounded Tier G repair queue.

### Tier C — Context-rich paper reproduction

Tier C additionally requires high-confidence agreement across paper/legend/methods, Gold Figure brief, experimental design, synthetic sample structure, inference, and Graph convention. The 50-case sample contained zero Tier C-certified cases.

### Excluded / needs repair

Exclude from paper-derived or Graph Gold use when there is:

- material paper-versus-Gold design conflict;
- incompatible unit/context abstraction;
- unresolved inferential unit;
- source abstraction that is internally inconsistent.

These cases can remain archived historical evidence and may still retain a narrowly documented Tier S regression value.

## Assignment rules for future versions

1. Keep original case IDs and immutable historical evidence.
2. Add a separately versioned context overlay or corrected case ID.
3. Record `sourceCaseId`, source hashes, reconstruction version, and whether synthetic raw was reused or regenerated.
4. Permit Tier S reuse when the original statistical/hierarchy contract is still correct.
5. Require a source-backed Figure brief before Tier G.
6. Require completed human scientific-context review before Tier C.
7. Never promote a case based only on a historical product PASS or attractive Graph output.
